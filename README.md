# 计算机解剖学 / Computer Atlas

中英文互动教学 MVP，默认英文。React + Three.js + Vite，无后端、无付费服务和 API 密钥。

右上角的语言菜单可切换 English / 中文，选择保存在当前浏览器中。切换语言不会重置选中部件、拆解程度、课程步骤或诊断状态。两种语言都支持搜索中文名称、英文名称和部件 ID。

`src/en.json` 保存英文翻译，`src/i18n.js` 负责语言偏好与结构化内容翻译。界面、29 个部件资料、模型标签、三条课程、诊断线索、动画阶段和辅助技术标签均支持两种语言；教学内容和部件 ID 继续由 `src/data.js` 管理。

## 运行

```sh
npm install
npm run dev -- --port 5173
```

打开终端给出的本地地址。`npm run build` 生成 `dist/`，可以部署到任意静态托管服务。`npm run preview` 预览构建产物。

## 内容

- 29 个独立可选择的程序化硬件结构
- 旋转、缩放、定位、标签、爆炸视图和侧板开关
- 拆解至 100% 时，可见部件按实际外形平铺为多行；保持相对尺寸，支持平移、缩放、标记点选与名称提示。拖回 0% 恢复组装。
- 6 个系统分层、中文与英文搜索、关联结构高亮
- 电力分支、四阶段数据流程，以及分开表现的固体传热与空气对流；支持暂停、逐步推进和重播
- 3 条包含操作验证的引导课程
- 开机诊断按断电、待机、启动中、运行推进；电源翘板开关、主板待机灯和机箱电源灯与状态联动
- 浏览器本地学习进度，桌面与手机布局，WebGL 失败时保留文字学习功能

`src/data.js` 保存结构化教学资料、部件关系、模型尺寸和课程步骤。`src/Scene.js` 是 Three.js 模型及交互实现。`src/main.jsx` 组织应用状态与教学流程。

`src/inventoryLayout.js` 负责适配视口的平铺排布。运行 `npm test` 检查不同宽高比下的部件覆盖、排布稳定性与无重叠约束。平铺状态禁用整体旋转，以保持目录平面；零件标记可通过键盘聚焦和选择。系统隐藏与侧板开关仍决定哪些部件出现在目录中。

`src/simulation.js` 集中定义设备供电状态、流程阶段和端点可见性规则。课程必须完成相关流程的全部阶段才能结束。减少动态效果偏好下使用静态箭头和手动推进，停止风扇、粒子和自动旋转。场景静止时按需绘制；说明窗口支持双向键盘焦点循环及关闭后焦点恢复。手机工具按钮为 44 × 44 px，播放流程时为阶段说明增加独立空间。

诊断采用常见的默认开机策略：接通交流只恢复待机，按机箱按钮后模拟硬件初始化。初始化时间是教学演示时长，不是实测 POST 时间；主板待机灯是本教学机型的配置，并非所有主板都具备。

## 模型与边界

### 硬件真实度更新

`src/hardwareGeometry.js` 集中维护硬件尺寸与细节几何，场景单位按 100 mm 建模。主板采用 244 × 305 mm ATX 外形，M.2 SSD 采用 2280 外形；DIMM、PCIe 插槽和 3.5 英寸硬盘也改用相应尺寸比例。CPU 顶盖与散热底座的接触、后置接口与机箱背面的对齐有自动测试。

新增 PCB 走线与丝印、内存插槽及锁扣、金手指、LGA 触点、CPU 顶盖、散热鳍片与连续热管、弯曲风扇叶片、显卡背板与散热罩、24 针 / 8 针供电接口、七针 L 形 SATA 接口、机箱铜柱与硬盘支架。电源与存储线束在组装和轻度拆解时显示，超过 35% 拆解后移除，以便观察零件；路径仍是概括性布线。

物理材质使用 Three.js 室内环境光照，所有几何和 PCB 图案均由项目代码生成，不依赖外部商业模型。完整尺寸约定、验证结果和简化范围见 `docs/MODEL.md`。

3D 几何是本项目独立制作的教学示意，不复制人体模型网站或商业硬件模型。布局参考通用 ATX 台式机，尺寸、连接、线缆与气流经过简化，不能替代真实主板手册。供电采用分支示意；数据流程省略缓存与并发；热流不是流体仿真。

依赖库保留各自许可：React、Vite、Lucide（MIT / ISC）、Three.js（MIT）。页面可选加载 Google Fonts 的 Noto Sans SC，无法连接时使用本机中文字体；应用与模型无需下载外部 3D 资源。

扩展真实机型时，可将程序化几何替换为具有清晰授权的 glTF，保持 `data.js` 中的部件 ID 与知识关系。当前实现不包含真实装机兼容性校验、机械精度仿真或多设备账号同步。
