# Computer Atlas / 计算机解剖学

[English](README.md) | **简体中文**

使用 React、Three.js 和 Vite 构建的计算机解剖互动教程。探索台式电脑、拆解硬件，并观察电力、数据和热量如何在部件之间流动。

应用在浏览器中运行，无需后端、付费服务或 API 密钥。默认英文，同时支持中文。

## 快速开始

安装当前的 Node.js LTS 版本及 npm，然后运行：

```sh
git clone https://github.com/qingfengzxr/computer-altas.git
cd computer-altas
npm install
npm run dev -- --port 5173
```

打开 Vite 输出的本地地址。如果端口被占用，以终端实际输出的地址为准。

| 命令 | 用途 |
| --- | --- |
| `npm run dev` | 启动开发服务 |
| `npm test` | 运行自动化测试 |
| `npm run build` | 将生产版本生成到 `dist/` |
| `npm run preview` | 本地预览生产构建 |

将 `dist/` 部署到静态托管服务即可。如果部署到 URL 子路径，需要在构建前配置 Vite 的 `base`。

## 功能

- **29 个可选部件**：旋转、缩放、定位、查看关联硬件，并切换标签或侧面板。
- **平铺拆解**：拆解至 100% 时，可见部件保持相对尺寸按行展开；拖回 0% 恢复组装。
- **六个系统分层**：筛选硬件，按中文名称、英文名称或部件 ID 搜索。
- **流程动画**：观察供电分支、四阶段数据流程，以及分别表现的固体传热与空气对流；支持暂停、手动推进和重播。
- **三条引导课程**：通过选择部件与观察流程逐步学习。
- **开机诊断**：恢复待机供电、按下机箱按钮、观察初始化；风扇、电源翘板开关和指示灯随供电状态变化。
- **桌面与手机布局**：学习进度保存在当前浏览器中；WebGL 不可用时仍可阅读教学内容。

## 语言切换

通过应用右上角的语言菜单切换英文与中文。选择保存在当前浏览器中，不会重置已选部件、拆解程度、课程步骤或诊断状态。

部件说明、模型标签、课程、诊断线索、流程阶段和无障碍标签均支持双语。无论界面使用哪种语言，搜索都接受中英文名称。

仓库说明文档通过两版 README 顶部的语言链接切换。

## 硬件模型与精度

几何模型和 PCB 图案均由项目代码生成，没有打包商业 3D 模型或厂商 CAD 资产。一个场景单位代表 100 mm。

| 实物参考 | 已建模细节 |
| --- | --- |
| Noctua NH-L9i | 官方 95 × 92 × 23 mm 散热器外形、含风扇总高 37 mm、54 片鳍片及两根直径 6 mm 的热管 |
| Noctua NF-A9x14 HS-PWM | 标称 92 × 92 × 14 mm 框架、82.5 mm 安装孔距及九片弯曲叶片 |
| Kingston KVR26N19S8/8 | 133.35 × 31.25 mm 外形、正面八颗 DRAM 芯片、288 个触点及贯穿的防呆缺口 |

参考部件的知识面板提供厂商规格链接。自动化测试检查生成网格是否符合已公开尺寸；未标注尺寸的形状、材质和小细节仍为近似。

通用硬件包含 PCB 走线、插槽固定结构、供电连接器、线束与后置接口。视频插座贴合显卡 PCB，并在初段拆解时随显卡移动。USB-A 和网口使用紧凑的连接器比例，网口具有八个触点和卡扣开口。

**这是教学模型，不是完整的 1:1 台式电脑复刻或制造级 CAD。** 主板、显卡、CPU／插槽、电源、存储和机箱没有绑定具体商业型号。教程不验证真实装机兼容性、电路连接或制造公差。

详细信息见[模型约定与简化范围](docs/MODEL.md)和[厂商资料与尺寸依据](docs/REFERENCES.md)。

## 教学逻辑与无障碍

- 接通交流电只恢复待机供电，按下机箱按钮后才开始模拟初始化。演示时长不是实测 POST 时间；待机灯代表本教学配置，并非所有主板都具备。
- 供电路径采用简化分支，数据流程省略缓存与并发；热量动画区分传导与对流，但不是流体仿真。
- 课程要求完成相关流程的全部阶段；隐藏端点不会留下孤立的动画链路。
- 开启减少动态效果偏好后，风扇、粒子与自动旋转停止，可使用静态箭头和手动推进。
- 场景静止时按需绘制；部件标记支持键盘选择，说明弹窗管理键盘焦点，手机工具按钮点击区域为 44 × 44 px。
- 流程说明位于 3D 画布之外，避免遮挡模型。线束在超过 35% 拆解后隐藏，便于观察部件。

## 验证

当前包含 23 项自动化测试，覆盖尺寸、显卡接口贴合、USB／网口开口、触点数量、平铺布局、供电状态迁移、流程规则和翻译。

浏览器检查覆盖桌面与手机布局、WebGL 非空渲染、部件近景、自动旋转，以及最大拆解时 29 个部件无重叠。这些检查不能代表所有实体手机的性能。生产构建通过，目前仍有 Vite 的 JavaScript 分块体积提示。

## 素材与依赖

React、Three.js、Vite 和 Lucide 保留各自的许可证。页面可选通过 Google Fonts 加载 Noto Sans SC，不可用时回退到本机字体。硬件几何无需下载外部 3D 资源。

扩展具体商业配置时，应使用厂商图纸或许可清晰的 CAD／glTF 素材，并保留部件 ID 与教学关系。当前应用不提供跨设备账号同步。
